# Аптека рядом

Учебное приложение на Expo и React Native. Исходный магазин канцтоваров переработан в каталог лекарств с Zustand.

## Что изменено

- данные читаются из `src/data/db.json` и соответствуют структуре лекарств;
- добавлены поиск и фильтрация по категориям;
- карточки показывают форму, дозировку, остаток и необходимость рецепта;
- корзина заменена на список препаратов к покупке без несуществующих цен;
- файлы и сущности переименованы с `Product` на `Medicine`;
- навигация переведена на Expo Router.

## Запуск

```bash
npm install
npm start
```

## Проверка

```bash
npm run typecheck
npm run lint
```
