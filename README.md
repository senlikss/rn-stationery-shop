# Аптека рядом

Учебное приложение на Expo и React Native. Исходный магазин канцтоваров переработан в каталог лекарств с Zustand.

## Что изменено

- данные читаются из `src/data/db.json` и соответствуют структуре лекарств;
- добавлены поиск и фильтрация по категориям;
- карточки показывают форму, дозировку, остаток и необходимость рецепта;
- корзина заменена на список препаратов к покупке без несуществующих цен;
- файлы и сущности переименованы с `Product` на `Medicine`;
- навигация переведена на Expo Router.

## Запуск

```bash
npm install
npm start
```

## Проверка

```bash
npm run typecheck
npm run lint
```

## Авторизация

При запуске открывается экран входа. Тестовые данные: логин `demo`, пароль
`Pharmacy123!`. Проверка учебная, выполняется на клиенте и не подходит для
производственной авторизации. Пароль скрыт по умолчанию; кнопка «Показать»
переключает видимость. При уходе в фон он снова скрывается.

Каталог, карточки лекарств и список покупок доступны только после входа,
включая переходы по прямым ссылкам. «Выйти» в каталоге завершает сеанс,
удаляет список покупок и возвращает на экран входа. Сеанс хранится только
в памяти: после перезапуска нужно войти заново. Пароли и OAuth-токены
не сохраняются в хранилище и не выводятся в логи.

### GitHub (Android / iOS)

Используется [OAuth Device Flow](https://docs.github.com/en/apps/oauth-apps/building-oauth-apps/authorizing-oauth-apps#device-flow).
Регистрация OAuth App обязательна: без Client ID реальная авторизация через
GitHub недоступна. Кнопка объясняет отсутствие настройки, тестовый вход работает.

1. В GitHub откройте Settings → Developer settings → OAuth Apps → New OAuth App.
2. Назовите приложение «Аптека рядом». Укажите URL своего репозитория как Homepage URL.
   Для обязательного поля Authorization callback URL можно указать
   `medicine-catalog://login`: Device Flow не использует redirect callback.
3. Включите **Enable Device Flow** в настройках созданного приложения.
4. Скопируйте `.env.example` в `.env` и задайте `EXPO_PUBLIC_GITHUB_CLIENT_ID`.
   Client ID является публичным. **Client Secret создавать и добавлять в приложение не нужно.**
5. Перезапустите Expo: `npx expo start --clear`.
6. Нажмите «Войти через GitHub», запомните показанный код и нажмите
   «Открыть GitHub». Введите код, подтвердите вход, закройте окно браузера
   и вернитесь в приложение. После получения профиля откроется каталог.

Интеграция не запрашивает доступ к приватным репозиториям или email. Обработаны
ожидание подтверждения, ограничение частоты запросов, отказ, отмена и истечение
кода. Для GitHub нужен интернет. В web-версии используйте тестовый вход:
прямые запросы Device Flow из браузера ограничены политикой CORS GitHub.

### Защита экрана

`expo-screen-capture` блокирует скриншоты и запись на экране входа Android/iOS.
Поля ввода появляются только после успешного включения защиты; при ошибке
вместо формы выводится сообщение. При выходе с экрана защита снимается.
При неактивном приложении форма дополнительно закрывается сплошным фоном.
В браузере запрет скриншотов технически недоступен, об этом сообщает экран.

После добавления нативных модулей используйте development build:
`npx expo run:android` / `npx expo run:ios` (с установленными платформенными
инструментами) или development build через EAS. Для проверки скриншотов на iOS
нужен iOS 13+. Физическое устройство обязательно для приёмки защиты.

### Проверка авторизации

Автоматические проверки (Node.js 22.16+):

```bash
npm run typecheck
npm run lint
npm run test:auth
```

Проверка на устройстве:

- При холодном запуске, прямой ссылке на лекарство и возврате назад без входа
  каталог не открывается.
- Неверные данные показывают ошибку; `demo` / `Pharmacy123!` открывают каталог.
- Пароль скрыт изначально, «Показать»/«Скрыть» работает; после сворачивания скрыт.
- Сделайте скриншот и запись при показанном пароле: форма не должна попасть
  в захват. После входа каталог снова можно снимать.
- Выполните GitHub-вход после настройки Client ID; отдельно проверьте отказ,
  отмену, повторную попытку и отключённый интернет.
- После «Выйти» каталог и список покупок недоступны по кнопке назад.
